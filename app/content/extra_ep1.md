### Answers

- **Q1 — B.** Questions 65න් **50**ක් විතරයි score වෙන්නේ, ඉතුරු 15 unscored test questions.
- **Q2 — C.** ESL +30 minutes accommodation එක exam එක book කරන්න **කලින්** request කරන්න ඕන.
- **Q3 — A.** Pass mark එක **700/1000** (scaled score).
- **Q4 — D.** Cloud Technology and Services = **34%**, domains අතරින් වැඩිම.
- **Q5 — B.** Cloud computing = on-demand delivery of IT resources over the internet, **pay-as-you-go**.
- **Q6 — A.** OS එකට control එක ඕන, hardware AWS බලාගන්නවා → **IaaS** (EC2).
- **Q7 — C.** Application එක පාවිච්චි කරනවා විතරයි → **SaaS**.
- **Q8 — D.** ඔක්කොම AWS එකේ run වෙනවා → **Cloud** deployment model.
- **Q9 — B, D.** Electricity/cooling සහ hardware replacement කියන්නේ on-premises **hidden costs**.
- **Q10 — A.** Regions කිහිපයක ඉක්මනින් deploy කරන එක → **Go global in minutes**.
- **Q11 — C.** Data center maintain කරන එක නවත්තලා business value වලට focus → **Stop spending money running and maintaining data centers**.
- **Q12 — D.** Resources විනාඩි වලින් ලැබීම → **Increase speed and agility**.
- **Q13 — A.** Manual විදිහට වැඩි කරන්න පුළුවන් නම් **Scalability**; ඉබේම වෙනවා නම් Elasticity.
- **Q14 — B.** Fail වුණත් **zero downtime** → Fault tolerance.
- **Q15 — C.** Multi-AZ → fail වුණත් දිගටම වැඩ කරනවා → **High availability**.
- **Q16 — A.** **EC2 Auto Scaling** demand අනුව instances ඉබේම add/remove කරනවා.
- **Q17 — D.** Database එක විතරක් always on → **Pilot light**.
- **Q18 — B.** වේගවත්ම recovery + වැඩිම cost → **Multi-site** (active-active).
- **Q19 — C.** Infrastructure as code, automation → **Operational Excellence**.
- **Q20 — A.** Least privilege සහ encryption → **Security** pillar.
- **Q21 — B.** ඕන නැති resources ඉවත් කරලා වියදම අඩු කිරීම → **Cost Optimization**.
- **Q22 — A, D.** Design principles: **Automate** සහ **Decouple**; tight coupling සහ manual වැඩ වැරදියි.
- **Q23 — C.** **Amazon SQS** queue එකෙන් tiers දෙක decouple කරනවා.
- **Q24 — D, E.** Technical perspectives: **Platform, Security, Operations**; Business, People, Governance කියන්නේ business පැත්ත.
- **Q25 — A.** Portfolio සහ risk management → **Governance**.
- **Q26 — D.** Monitoring සහ incidents → **Operations** perspective.
- **Q27 — B.** Confidentiality, integrity, availability → **Security** perspective.
- **Q28 — C.** VMware → VMware Cloud on AWS = **Relocate**.
- **Q29 — A.** භාවිතා නොකරන apps off කරනවා → **Retire**.
- **Q30 — D.** Cloud-native විදිහට අලුතෙන් ලියනවා → **Refactor** (වැඩිම effort).
- **Q31 — B.** Database එක වැඩ කරද්දිම migrate කරන්න → **AWS DMS**.
- **Q32 — C.** DB engine වෙනස් වෙනකොට schema convert කරන්නේ **AWS SCT**.
- **Q33 — A.** Servers lift-and-shift කරන්න → **Application Migration Service (MGN)**.
- **Q34 — D.** Network එකෙන් on-prem → S3 data copy කරන්න → **DataSync**.
- **Q35 — A, B.** **Rehost = lift and shift**, **Repurchase = drop and shop**.
- **Q36 — B.** AWS එකෙන්ම license එක්ක ගන්නවා → **License included**; තමන්ගේ license ගෙනාවොත් BYOL.
- **Q37 — C.** Instance එක **ලොකු** කරනවා → **Vertical scaling** (scale up).
- **Q38 — D.** ලාභම → ගණන්ම: Backup & restore, Pilot light, Warm standby, Multi-site.
- **Q39 — B, D.** Root user ට **MFA** දාන්න සහ **AWS Budgets** alert එකක් හදන්න.
- **Q40 — A.** **SaaS** එකේ customer ට manage කරන්න ඕන දේවල් අඩුම.
